# 사용법

화면 순서대로 따라 하는 사용 방법입니다. 아직 설치하지 않았다면 [처음 설치하기](getting-started.md)부터 진행하세요.

## 전체 흐름

| 단계 | 하는 일 | 위치 |
|---|---|---|
| 1 | 학생 제출물 받기 | **저장소 동기화** 버튼 |
| 2 | 분반·장·문제와 학생 고르기 | 왼쪽 **1**, **2** 영역 |
| 3 | 테스트 케이스 만들기 (없을 때만) | **AI 케이스 생성** 버튼 |
| 4 | 채점하기 | 아래 **3 일괄 채점 실행** 영역 |
| 5 | 결과 확인·점수 조정 | 오른쪽 **채점 결과** 탭 |
| 6 | 정성평가 (선택) | **Qwen 정성평가** 버튼 |
| 7 | CSV로 내보내기 | **장 골라 CSV 내보내기** 버튼 |

결과는 모두 자동 저장됩니다. 따로 저장 버튼을 누를 필요가 없고, 앱을 다시 열어도 그대로 남아 있습니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| **1 분반과 문제 선택** | 저장소 동기화, 연도·분반·장·문제 선택, AI 케이스 생성 |
| **2 채점할 학생 선택** | 대상 학생 목록, Qwen 정성평가 |
| 오른쪽 탭 | **채점 결과**, **제출 코드**, **직접 실행**, **실행 로그** |
| **3 일괄 채점 실행** | 채점 대상 요약, 채점 시작·중지, 진행률 |
| **도구 / 고급** 메뉴 | 실행 환경 설정, 내보내기, 예전 기록 가져오기, 실습 자료 |

오른쪽 위에서 **화면 모드**(라이트·다크)와 **글자 크기**를 바꿀 수 있습니다.

---

## 1. 학생 제출물 받기

1. **저장소 동기화** 버튼을 누릅니다.
2. 학생 명단 CSV를 고릅니다. 예: `testdata\2026\system_3.csv`
3. 끝나면 완료 창에서 성공·실패 인원과 실패 사유를 확인합니다.

> - 이미 받아 둔 분반이면 이 단계를 건너뛰고 **연도**와 **분반**만 고르면 됩니다.
> - 학생 폴더에 직접 수정한 파일이 있으면 그 학생은 덮어쓰지 않고 건너뜁니다.

## 2. 분반·문제와 학생 고르기

1. **연도 → 분반 → 장 → 문제** 순서로 고릅니다.
2. 분반을 고르면 학생이 **전체 선택**된 상태로 나옵니다.
3. 빼고 싶은 학생은 클릭해서 해제합니다. **전체 선택 / 선택 해제** 버튼도 있습니다.

> 문제 목록 옆의 숫자는 그 문제에 준비된 테스트 케이스 수입니다. `케이스 없음`이면 3단계로 케이스를 먼저 만드세요.

## 3. 테스트 케이스 만들기

케이스가 없는 문제만 하면 됩니다. Qwen 서버 설정이 필요합니다.

1. **AI 케이스 생성** 버튼을 누릅니다.
2. **슬라이드 목록에서 문제 선택…** 버튼으로 강의 슬라이드의 문제 페이지를 고릅니다. 문제 설명을 직접 입력해도 됩니다.
3. 상단 **생성·저장 대상**에서 장·문제를 확인하고 만들 케이스 수를 정합니다.
4. 정답 코드가 있으면 **기준 코드**로 고릅니다.
5. **Qwen으로 테스트 케이스 생성**을 누르고 결과를 확인합니다.
6. **검증된 케이스 · 채점에 추가**를 누르면 바로 채점에 쓸 수 있습니다.

> - 기준 코드가 없으면 내용을 직접 확인한 뒤 **수동 검토**를 체크해야 추가됩니다.
> - 아직 확인 전이라면 **초안 저장 · 채점 제외**로 보관만 해 둘 수 있습니다.

## 4. 채점하기

1. 아래 요약에서 학생 수와 케이스 수를 확인합니다.
2. 파란색 **선택 N명 일괄 채점** 버튼을 누릅니다.
3. 학생 한 명이 끝날 때마다 결과 표가 채워집니다.

> - **중지**를 누르면 지금 채점 중인 학생까지 저장하고 멈춥니다.
> - 일부 학생이나 한 문제만 다시 채점해도 나머지 결과는 그대로 남습니다.

## 5. 결과 확인과 점수 조정

**채점 결과** 탭에서 합니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 학생별 자세한 결과 보기 | 학생 행을 고르고 **상세 근거 보기** (행을 두 번 클릭해도 됨) |
| 점수 고치기 (중간고사) | 학생 행을 고르고 **문제 점수 조정** → 점수와 사유 입력 |
| 예전 채점 결과 보기 | 결과 표 아래 **최신 점수표 (기본)** 목록에서 과거 실행 선택 |
| 최신 결과로 돌아오기 | **최신값 새로고침** |
| 정렬하기 | 열 제목 클릭 |
| 학생 코드 보기 | **제출 코드** 탭에서 파일을 두 번 클릭 |
| 직접 실행해 보기 | 학생 한 명만 고르고 **직접 실행** 탭 |

> 고친 점수는 사유와 함께 기록되고, 다시 채점해도 유지됩니다.

## 6. Qwen 정성평가 (선택)

AI가 학생 코드를 검토해 점수를 제안하면, 교수자가 확인하고 확정하는 기능입니다. Qwen 서버 설정이 필요합니다.

1. 메인 화면에서 분반·장·문제와 학생을 고르고 **Qwen 정성평가**를 엽니다.
2. 문제 내용을 확인합니다. 비어 있으면 **슬라이드 목록에서 문제 선택…** 버튼으로 불러오거나 직접 입력합니다.
3. 평가할 학생을 고르고 **선택 N명 일괄 정성평가**를 누릅니다.
4. 학생을 하나씩 눌러 AI의 제안 점수와 의견을 확인합니다.
5. 점수를 확정합니다.

| 확정 방법 | 버튼 |
|---|---|
| 한 명씩 점수·의견을 고쳐서 확정 | **현재 학생 점수 확정** |
| 여러 명을 제안 점수 그대로 확정 | 학생들을 고르고 **선택 학생 일괄 승인** |

> - 실패한 학생만 다시 하려면 **미평가·실패 선택**을 누른 뒤 **선택 N명 일괄 정성평가**를 누릅니다.
> - 창을 다시 열면 지난 평가를 자동으로 불러옵니다.
> - 확정한 점수는 메인 **채점 결과** 표에도 나타납니다.

## 7. CSV로 내보내기

| 버튼 | 저장되는 범위 |
|---|---|
| **장 골라 CSV 내보내기** (채점 결과 탭 아래) | 체크한 장들을 파일 하나로 저장합니다. |
| **도구 / 고급 → CSV / JSON 내보내기…** | 지금 화면의 분반·장·문제만 저장합니다. |

- 학생 한 명이 한 행입니다. 여러 장을 고르면 `chapter`, `problem` 열로 구분됩니다.
- Excel에서 바로 열 수 있습니다(한글 깨짐 없음).
- 항상 저장하는 순간의 최신 결과로 저장됩니다.

> 정성평가 창의 **CSV / JSON 저장**은 정성평가 결과만 따로 저장합니다.

## 8. 기록 관리

| 하고 싶은 것 | 방법 |
|---|---|
| 백업하기, 다른 컴퓨터로 옮기기 | 앱을 닫고 `data\swlab.db` 파일을 복사 |
| 채점 결과 파일 폴더 열기 | 과거 실행을 고르고 **결과 폴더 열기** |
| 다른 컴퓨터의 결과 파일 열기 | **이전 결과 열기** → `run.json` 선택 |
| 예전 `reports\` 결과를 DB로 옮기기 | **도구 / 고급 → 이전 채점·정성평가 기록을 DB로 가져오기** |

## 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 오류 창에 "프로그램을 다시 실행하세요"가 나옴 | 업데이트로 코드가 바뀐 상태입니다. 앱을 닫고 다시 엽니다. |
| 무슨 일이 있었는지 더 보고 싶음 | **실행 로그** 탭을 보거나 `scripts\launch_gui.cmd`로 실행해 콘솔을 봅니다. |
| 설치·환경 문제 | [처음 설치하기의 자주 생기는 문제](getting-started.md#자주-생기는-문제)를 봅니다. |
