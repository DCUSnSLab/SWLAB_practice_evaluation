# 사용법

SWLAB 실습 평가 시스템의 화면별 사용 순서입니다. 아직 설치하지 않았다면 [처음 설치하기](getting-started.md)부터 진행하세요.
세부 규칙(케이스 파일 형식, 점수 계산식, CSV 열 전체)은 [README](../README.md)에 있습니다.

## 한눈에 보는 흐름

```
저장소 동기화 → 연도·분반·장·문제 선택 → (케이스가 없으면) AI 케이스 생성
  → 학생 선택 → 선택 N명 일괄 채점 → 채점 결과 확인·점수 조정
  → (선택) Qwen 정성평가 → CSV 내보내기
```

모든 결과는 `data\swlab.db`에 자동 저장됩니다. 따로 저장 버튼을 누를 필요가 없고, 앱을 다시 열어도 그대로 남아 있습니다.

## 메인 화면 구성

| 영역 | 하는 일 |
|---|---|
| **1 분반과 문제 선택** | 저장소 동기화, 연도·분반·장·문제 선택, AI 케이스 생성 |
| **2 채점할 학생 선택** | 채점·정성평가 대상 학생 선택, Qwen 정성평가 열기 |
| 오른쪽 탭 | **채점 결과**, **제출 코드**, **직접 실행**, **실행 로그** |
| **3 일괄 채점 실행** | 채점 대상 요약, **선택 N명 일괄 채점**, **중지**, 진행률 |
| **도구 / 고급** 메뉴 | 실행 환경 설정, 내보내기, 예전 기록 가져오기, 배점 명세 채점, 실습 자료 등 |

오른쪽 위에서 **화면 모드**(시스템 설정·라이트·다크)와 **글자 크기**(12·14·16pt)를 바꿀 수 있고, 다음 실행에도 유지됩니다.

## 1. 학생 제출물 받기 — 저장소 동기화

1. **저장소 동기화**를 누르고 학생 명단 CSV(예: `testdata\2026\system_3.csv`)를 고릅니다.
2. 학생별 GitHub 저장소를 처음이면 내려받고(clone), 이미 있으면 최신 커밋으로 갱신(pull)합니다.
3. 완료 창에서 성공·실패 인원과 실패한 학생의 이름·학번·사유를 확인합니다.

- 제출물은 `src\origin\<과목>_<분반>_<연도>\<학번>\`에 저장됩니다.
- 학생 폴더 안에 직접 수정한 파일이 있으면 그 학생은 덮어쓰지 않고 건너뜁니다.
- 이미 받아 둔 분반이면 동기화 없이 **연도**와 **분반**만 고르면 됩니다.

## 2. 채점 대상 고르기

1. **연도 → 분반 → 장 → 문제** 순서로 고릅니다. 문제 목록에는 `채점 N개`(활성 케이스 수), `초안 N개`, `케이스 없음`이 함께 표시됩니다.
2. 분반을 고르면 학생 **전체가 기본 선택**됩니다. 학생을 클릭하면 포함·제외가 바뀌고, **전체 선택 / 선택 해제** 버튼도 있습니다. Ctrl/Shift는 필요 없습니다.
3. 아래 **3 일괄 채점 실행**의 요약(`학생 N명 × 케이스 M개`)을 확인합니다.

**중간고사(`midterm`)** 를 고르면 문제 목록에 C 파일별 문제와 **전체 문제**가 나옵니다. 문제 배점 × 필수 케이스 통과 비율로 부분점수를 계산해 75점 만점으로 합산합니다.

## 3. 테스트 케이스가 없을 때 — AI 케이스 생성

케이스가 없는 문제는 채점할 수 없습니다. **AI 케이스 생성**을 눌러 만듭니다. Qwen 서버 설정이 필요합니다.

1. **슬라이드 목록에서 문제 선택…** 버튼으로 PPT 문제 페이지를 고르거나 문제 설명을 직접 입력합니다.
2. 상단 **생성·저장 대상**에서 장·문제와 저장 폴더를 확인하고 케이스 수(1–10개)를 정합니다.
3. 올바른 **기준 코드**를 고릅니다. 오답 예제를 추가하면 케이스가 그 오류를 잡는지도 검사합니다.
4. **Qwen으로 테스트 케이스 생성** → 결과 확인 → **검증된 케이스 · 채점에 추가**를 누릅니다.
   - 기준 코드가 없으면 기대값을 직접 확인하고 **수동 검토**를 체크해야 추가됩니다.
   - 검토 전이면 **초안 저장 · 채점 제외**로 보관만 할 수 있습니다.

저장한 케이스는 `testcase\<과목>\<장>\<문제>\`에 들어가고, 메인 화면 문제 목록의 활성 개수가 바로 늘어납니다.

## 4. 채점하기

1. 파란색 **선택 N명 일괄 채점**을 누릅니다.
2. 학생마다 케이스별로 컴파일·실행해 출력, 파일, 종료 코드를 비교합니다. 학생 한 명이 끝날 때마다 표와 DB가 갱신됩니다.
3. **중지**를 누르면 현재 학생까지 저장하고 멈춥니다. 나머지 학생은 미실행으로 남습니다.

일부 학생이나 한 문제만 다시 채점해도 다른 학생·문제의 결과는 그대로 유지됩니다.

## 5. 결과 보기와 점수 조정 — 채점 결과 탭

- **표 기호:** `O` 통과, `△` 일부 통과, `X` 통과 없음, `—` 미판정입니다. 열 제목을 클릭하면 정렬됩니다.
- **최신 점수표 (기본):** 학생·문제별로 가장 최근 실행 결과와 정성평가, 수동 조정을 모아 보여 줍니다. 목록에서 과거 실행을 고르면 당시 결과를 조회하고, **최신값 새로고침**으로 다시 최신 점수표로 돌아옵니다.
- **상세 근거 보기:** 학생 행을 고르고 누르면 케이스별 기대값, 실제 출력, 오류를 볼 수 있습니다. 행을 두 번 클릭해도 열립니다.
- **문제 점수 조정:** 중간고사에서 학생을 고르고 문제 점수를 사유와 함께 바꿉니다. 조정 이력이 남고, 다시 채점해도 조정 점수가 유지됩니다.
- **제출 코드 탭:** 선택 학생의 제출 파일을 두 번 클릭하면 소스를 봅니다.
- **직접 실행 탭:** 학생 한 명을 고르고 인자·표준입력을 넣어 직접 실행해 봅니다.

## 6. Qwen 정성평가

코드 품질을 AI가 평가하고 교수자가 확정하는 기능입니다. Qwen 서버 설정이 필요합니다.

1. 메인 화면에서 분반·장·문제와 학생을 고른 뒤 **Qwen 정성평가**를 엽니다. 같은 문제의 지난 평가가 있으면 학생별 최신 평가를 자동으로 불러옵니다.
2. 요구사항을 확인합니다. 중간고사는 시험지 문제와 배점이 자동으로 채워지고, 다른 문제는 **슬라이드 목록에서 문제 선택…** 버튼으로 불러오거나 직접 입력합니다.
3. **평가 기준 / 배점** 탭에서 항목(정확성·알고리즘·가독성·문제 이해도·자원 관리)과 문제 배점을 확인합니다.
4. 학생 표에서 대상을 고르고 **선택 N명 일괄 정성평가**를 누릅니다. 실패한 학생만 다시 하려면 **미평가·실패 선택**을 누른 뒤 같은 버튼을 누릅니다.
5. 학생을 고르면 종합 품질, 제안 부분점수, 항목별 평가와 코드 근거가 보입니다.
6. 점수를 확정합니다.
   - 한 명씩: 확정 점수와 검토 의견을 고치고 **현재 학생 점수 확정**을 누릅니다.
   - 여러 명을 제안 점수 그대로: 학생을 고르고 **선택 학생 일괄 승인**을 누릅니다.

- 점수는 정수로 **올림** 계산합니다.
- 제출 폴더나 파일이 없거나 빈 파일이면 AI를 부르지 않고 **제출 상태 0점**으로 기록합니다.
- 서버 오류는 **평가 실패**로 점수를 비워 두므로 0점과 구분됩니다.
- 정성평가 결과는 메인 **채점 결과** 표에 `정성 1번`, `정성 2-(2)` 같은 열로 나타납니다. 중간고사 전체 보기에는 **정성 총점**(확정 점수 우선, 미확정은 AI 제안의 합)도 표시됩니다.
- 학생 코드가 Qwen 서버로 전송됩니다. 학번·이름 명단은 따로 보내지 않습니다.

## 7. 점수표 내보내기 — CSV

| 방법 | 범위 |
|---|---|
| **장 골라 CSV 내보내기** (채점 결과 탭 아래 저장 위치 칸 옆, **도구 / 고급** 메뉴에도 있음) | 체크한 장들을 파일 하나로 저장합니다. 중간고사는 전체 문제 보기, 다른 장은 기록된 문제마다 학생당 한 행이며, `chapter`·`problem` 열로 구분합니다. |
| **도구 / 고급 → CSV / JSON 내보내기…** (상세 근거 창에도 있음) | 지금 화면의 분반·장·문제만 저장합니다. JSON을 고르면 출처 실행과 정성평가 상세까지 담습니다. |

- **최신 기준:** 두 방법 모두 저장 직전에 DB를 다시 읽어 최신 점수표를 학생당 한 행으로 저장합니다. 과거 실행을 조회하는 중이어도 같습니다.
- **엑셀:** Excel에서 한글이 깨지지 않는 UTF-8 BOM으로 저장합니다. 학생 출력이 수식으로 실행되지 않게 처리합니다.
- **빈칸과 0점:** 미평가는 빈칸, 실제 0점은 `0`입니다.

정성평가 창의 **CSV / JSON 저장**은 정성평가만 따로 저장합니다. 학생별 요약 CSV, 항목별 상세 CSV, JSON 중에서 고를 수 있습니다.

## 8. 기록 관리

- **저장 위치:** 모든 기록은 `data\swlab.db`에 있습니다. 백업하거나 다른 컴퓨터로 옮길 때는 앱을 닫고 이 파일을 복사합니다.
- **사본:** 채점 실행마다 `reports\case-grading\<실행시각_식별자>\`에도 `run.json`, `cases.csv`, `summary.csv` 사본이 생깁니다. **결과 폴더 열기**로 찾아갈 수 있습니다.
- **다른 PC의 결과:** 다른 컴퓨터에서 가져온 `run.json`은 **이전 결과 열기**로 엽니다. 연 기록은 DB에도 들어갑니다.
- **예전 결과 폴더:** DB가 생기기 전의 `reports\` 결과 폴더는 **도구 / 고급 → 이전 채점·정성평가 기록을 DB로 가져오기**로 한 번에 넣습니다.

## 문제가 생겼을 때

- **오류 창이 뜰 때:** 앱은 꺼지지 않습니다. 내용에 *프로그램을 다시 실행하세요*가 있으면 `git pull` 등으로 코드가 바뀐 상태이니 앱을 닫고 다시 엽니다.
- **원인을 더 보고 싶을 때:** **실행 로그** 탭을 보거나 `scripts\launch_gui.cmd`로 실행해 콘솔 출력을 확인합니다.
- **설치·환경 문제:** [처음 설치하기의 자주 생기는 문제](getting-started.md#자주-생기는-문제)를 봅니다.
