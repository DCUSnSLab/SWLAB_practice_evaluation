# 여러 파일로 구성된 교수자 기준 코드

AI 케이스 생성 창에서 **파일 선택…** 버튼을 누르고 한 프로그램을 이루는 파일들을 함께 선택합니다.

- C: `main.c`, `copy.c`, `copy.h` 같은 소스·헤더를 Ctrl/Shift로 함께 선택합니다. 선택한 모든 `.c` 파일을 링크하고 헤더 폴더를 검색 경로에 추가합니다.
- Python: 실행 스크립트와 함께 사용하는 모듈 `.py`를 선택하고, 옆 실행 파일 목록에서 시작할 스크립트를 고릅니다.
- 헤더는 실행 파일 목록에 표시하지 않습니다. 선택 파일의 전체 경로는 파일 표시란에 마우스를 올리면 볼 수 있고, **해제**로 선택을 비웁니다.

여러 폴더에서 지정된 파일도 공통 상위 폴더를 기준으로 상대 경로를 유지합니다. 파일 선택은 선택 목록을 교체하며, 한 번에 하나의 기준 프로그램을 구성합니다. 각자 `main()`이 있는 독립적인 C 프로그램들은 각각 따로 검증해야 합니다.

선택한 파일만 복사해 Docker에서 실행합니다. 같은 폴더의 선택하지 않은 다른 프로그램이나 기존 실행 결과는 복사하지 않습니다. 필요한 보조 데이터는 케이스의 fixtures에 지정합니다. 소스·헤더는 LLM 서버에 전송하지 않습니다.

검증을 시작할 때 전체 파일의 내용을 고정하고 같은 사본으로 두 번 실행합니다. 검증 기록에는 실행 파일과 선택한 모든 파일의 해시를 보관합니다. 파일 선택·실행 파일을 바꾸면 검증을 해제하고, 파일 내용이 외부에서 바뀌거나 삭제돼도 채점에 추가하기 전에 다시 검증해야 합니다.
